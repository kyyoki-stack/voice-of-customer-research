# 用户之声研究 Skill · 0.1.0

将真实公开评论整理为匿名原声、AI洞察、数据报告、11部分MRD和单文件HTML。采用当前项目的气泡首页、留白布局、渠道筛选、需求卡片和报告阅读/下载设计。

## 安装

将`voice-of-customer-research`文件夹复制到Codex的`~/.codex/skills/`，或其他支持SKILL.md的软件对应技能目录。刷新技能列表或重启宿主。跨宿主安装位置和可用工具不同，未在所有软件中验证。

调用示例：
> 使用 voice-of-customer-research，调研魏牌座舱AI语音助手，优先2025年10月至2026年10月的真实用户评价。输出原声、需求洞察、数据报告、MRD，并生成HTML页面。

## 前置条件与输出

Python 3.9+；宿主模型负责语义分析。采集使用宿主网页工具或选装的Agent-Reach/OpenCLI及平台登录。无需为渲染器配置LLM API；平台工具若需凭据应在本地配置。仅安装本包不等于平台连通。

每次独立研究项目：
- `docs/00-项目说明.md`、`01-数据分析报告.md`、`02-MRD.md`、`03-洞察总结.md`
- `data/feedback.csv`、`needs.csv`、`source_audit.csv`
- 根目录`research.html`，数据内嵌，可离线打开；来源链接需联网。

HTML呈现全部相关反馈、好评差评、AI总结、痛点/场景/任务影响、优先级、真实证据、版本、数据报告与MRD。未知版本不能当指定OTA体验。文档展示为可展开的原始Markdown全文；可下载，不承诺富文本排版。搜索框只筛选已有数据。

## 验证范围

已用当前座舱案例的67条已采集记录（41条相关）验证标准化渲染、8项需求证据关联和报告嵌入。没有重新采集平台评论；没有证明空环境一句话全程自动成功，也未完成跨宿主、浏览器视觉或所有平台连通性验证。

发布包仅包含Skill代码与模板，不包含本项目实际评论、账号信息或凭据。发布前检查包内清单，认证可用后创建GitHub仓库并上传独立包，不上传整个知识库。
