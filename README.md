# 用户之声研究 Skill

从真实用户反馈中发现需求，生成可追溯的研究报告和可浏览的 HTML 页面。适用于 Codex 等支持 `SKILL.md` 的 AI 工具；不同宿主的采集工具和登录条件需要单独配置。

## 目的／用途

帮助产品经理、研究人员和产品团队了解用户如何评价产品、在什么场景遇到问题，以及希望得到什么结果，为产品迭代和新方向探索提供依据。

适合用来：

- 汇总不同平台的真实好评、差评和功能建议。
- 分析使用场景、痛点、任务影响与期望结果。
- 比较用户对产品和替代方案的反馈，提出需求优先级与待验证机会。
- 将原声、AI 洞察和研究报告放在同一个页面中查看与分享。

公开评论属于探索性证据，不能直接代表所有用户，也不能单凭评论证明市场规模、实际留存或商业可行性。

## 输入

最基本需要提供：**要调研的产品，以及关注的主题或决策问题**。

可进一步指定：

| 输入 | 示例 |
|---|---|
| 产品／品牌／竞品 | 魏牌座舱 AI 助手；或指定其他产品 |
| 调研主题 | 语音识别、导航理解、连续指令、用户吐槽与好评 |
| 决策用途 | 寻找迭代需求、了解竞品不足、探索新产品机会 |
| 渠道 | 汽车之家、B站、小红书、公开论坛等可访问来源 |
| 时间窗口 | 参考：2025年10月至2026年10月 |
| 软件版本 | 指定 OTA 或产品版本；版本未知单独标注 |
| 已有资料 | 已采集的匿名评论 CSV、来源记录或研究说明 |

调用示例：

> 使用 voice-of-customer-research，调研魏牌座舱 AI 助手在2025年10月至2026年10月的真实用户反馈，重点关注语音识别与导航。输出原声、需求洞察、数据报告、MRD，并生成 HTML 页面。

AI 继承项目中已确认的范围，只询问影响执行的缺失信息。平台需要登录或凭据时，在用户本地配置，不将 Cookie 或 Token 写入报告与发布包。

## 输出：会得到什么

| 产物 | 内容 |
|---|---|
| 匿名原声数据 | 真实评论、来源链接、时间与版本、相关性审核和好评／差评标注 |
| AI 需求洞察 | 使用场景、痛点、期望结果、任务影响、证据强度，以及可追溯的原声依据 |
| 需求清单 | P0／P1／P2、判断理由、建议行动和验证方法 |
| 数据分析报告 | 采集范围、筛选方法、统计、来源覆盖和数据局限 |
| MRD 研究报告 | 背景与目标、市场、用户、需求、竞品、定位、优先级、商业假设、指标、风险和里程碑，共11部分 |
| HTML 研究页面 | 原声库、需求洞察、报告阅读与下载；支持渠道、关键词、年份和软件版本筛选 |

默认交付目录：

```text
研究项目/
├── docs/                 # 项目说明、洞察、数据报告与 MRD
├── data/                 # 匿名评论、需求和来源审核 CSV
└── research.html         # 内嵌研究数据，可离线打开的页面
```

HTML 中的搜索只筛选已采集数据，不会直接触发联网采集。来源链接需要联网访问。AI 推断和商业假设与原声事实分别标明；证据不足时明确写出，不编造评论、数字或结论。

## 安装与运行条件

下载 [v0.1.0 安装包](https://github.com/kyyoki-stack/voice-of-customer-research/releases/tag/v0.1.0)，将 `voice-of-customer-research` 文件夹复制到宿主技能目录。Codex 使用 `~/.codex/skills/`，刷新技能列表或重启后调用。

- Python 3.9+ 用于数据校验和 HTML 生成。
- 宿主 AI 模型执行语义分析；渲染器不需要额外的 LLM API。
- 采集依赖宿主网页工具，或已配置的 Agent-Reach／OpenCLI 与平台登录。安装 Skill 不等于所有平台均已连通。

## 当前验证范围

已用座舱案例的67条采集记录、41条相关反馈、8项需求验证数据校验和 HTML 生成。尚未验证全新环境下“一句话完成采集到页面”的完整流程，也未验证所有宿主及所有平台的兼容性。

公开仓库与安装包仅包含代码、规则和模板，不包含该案例的实际评论数据、账号信息或凭据。

## 研究页面布局

首页标题保持单行，气泡下方不显示额外说明；结果区先显示“用户怎么说？”，再显示研究主题。页面保留原声库、需求洞察、研究报告与筛选，移除用途、输入、输出的介绍栏。研究范围和数据局限仍在报告及证据详情中展示。

生成页面时可用 `--hero-title` 指定首页标题，例如：

```bash
python3 voice-of-customer-research/scripts/render.py --project /path/to/research --title "产品语音助手用户反馈研究" --hero-title "产品助手，用户怎么说？"
```

公开仓库只保存通用模板和渲染代码；生成页面内嵌的实际研究数据保存在各自研究目录中。
